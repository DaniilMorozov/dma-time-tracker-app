# DMA Time Tracker — app page

Installable web page (PWA) for the **DMA YouTrack Time Tracker** Chrome extension: it frames the
extension's window mode so the tracker gets a Dock / taskbar icon and its own window. The extension
must be installed in the same Chrome profile; without it the page explains what to do.

The source of this folder is `app/` in the extension repository; copy it here to update.
